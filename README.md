# stofs-cf-ugrid

Make STOFS-3D-Atlantic (SCHISM) output CF and UGRID compliant: metadata fixes, checker commands and before/after tests.

The notebook (CF-Ugrid.ipynb) works on STOFS-3D-Atlantic v3.1 netCDF files.
The data are not stored in this repository (each 3D file is about 8 GB). They are public
and free, and an AWS account is not needed.

  Bucket        : s3://noaa-nos-stofs3d-pds
  
  Folder        : STOFS-3D-Atl/
